# Security policy

Do not report suspected vulnerabilities in public issues or pull requests. Use
[GitHub private vulnerability reporting](https://github.com/kwokchunghim/ai-project-cookiecutter/security/advisories/new).
If that form is unavailable, contact `@kwokchunghim` through a private channel listed
on their GitHub profile.

Include the affected revision, impact, reproduction steps, and any suggested mitigation.
Do not include real credentials, personal data, production prompts, or other secrets.

Security fixes target the latest `main` revision. Repositories generated from an earlier
template revision are independent snapshots and should follow their own security policy.
